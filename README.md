# 파형 플레이어 (Waveform Player)

영상·오디오 파일의 **파형을 보면서** 재생하고, **무음 구간을 자동으로 건너뛸 수 있는** 브라우저용 플레이어입니다.

👉 **바로 사용하기: https://mugamta.github.io/WaveformPlayer/**

설치나 서버가 필요 없습니다. `index.html` 파일 하나로 동작합니다. 파일은 브라우저 안에서만 처리되므로 **어디에도 업로드되지 않습니다.**

## 주요 기능

- **파형 표시**: 확대해서 보는 상세 파형과 전체 개요 파형을 함께 보여줍니다. 클릭하거나 드래그해서 원하는 위치로 이동할 수 있습니다.
- **무음 자동 스킵**: 설정한 기준보다 조용한 구간을 자동으로 건너뜁니다. 건너뛰는 구간은 파란색으로 표시됩니다.
- **소리 구간 이동**: 다음/이전 소리가 시작되는 지점으로 바로 이동합니다.
- **프레임 단위 이동**: FPS를 자동으로 감지하며, 직접 입력할 수도 있습니다. 1프레임씩 앞뒤로 이동할 수 있습니다.
- **플레이리스트**: 여러 파일을 한 번에 열고 이전/다음 파일로 넘길 수 있습니다.
- **재생 속도 조절**: 0.5배부터 3배까지 고를 수 있습니다.
- **설정 자동 저장**: 설정은 브라우저(localStorage)에 저장되어 다음에 열어도 그대로 유지됩니다.

## 사용법

1. **파일 열기** 버튼을 누르거나, 파일을 화면에 **드래그앤드롭**합니다. 여러 파일을 한꺼번에 열 수 있습니다.
   - 드롭할 때 `Shift` 또는 `Ctrl`을 누르고 있으면 기존 목록 뒤에 추가됩니다.
2. 파형이 분석되면 바로 재생할 수 있습니다.
3. 무음을 건너뛰려면 **무음 자동 스킵**을 켭니다(`A` 키).

### 설정 항목

| 항목 | 설명 |
|---|---|
| ←/→ 이동 | 화살표 키로 한 번에 이동할 양 (프레임 / 초 / 영상 길이의 %) |
| FPS | 프레임 이동 기준. `0`이면 자동 감지 |
| 무음 기준 | 이 값(dB)보다 작은 소리를 무음으로 판단 |
| 이만큼 이상 조용하면 스킵 | 무음이 이 시간(초) 이상 이어질 때만 건너뜀 |
| 앞 여유 / 뒤 여유 | 소리 앞뒤로 남겨둘 여유 시간(초) |
| 파형 보이는 범위 | 상세 파형에 한 번에 보이는 길이(초). 위쪽 파형에서 마우스 휠로도 조절 가능 |

## 단축키

| 키 | 동작 |
|---|---|
| `Space` | 재생 / 정지 |
| `←` / `→` | 설정한 단위만큼 이동 |
| `,` / `.` | 1프레임 뒤로 / 앞으로 |
| `B` / `N` | 이전 / 다음 소리 구간 |
| `A` | 무음 자동 스킵 켜기/끄기 |
| `PageUp` / `PageDown` | 이전 / 다음 파일 |
| `↑` / `↓` | 볼륨 올리기 / 내리기 |
| `M` | 음소거 |
| `P` | 플레이리스트 보이기/숨기기 |
| `H` | 전체모드 (하단바·목록 숨김) |
| `Esc` | 전체모드 해제 |
| `F` | 브라우저 전체화면 |

## 로컬에서 실행하기

이 저장소를 내려받은 뒤 `index.html`을 브라우저로 열면 됩니다.

## 참고

- 브라우저가 재생할 수 있는 형식(MP4, WebM, MP3, WAV 등)만 지원합니다. 지원 범위는 브라우저마다 다를 수 있습니다.
- 아주 긴 파일은 파형을 분석하는 데 시간이 걸리고 메모리를 많이 쓸 수 있습니다.
